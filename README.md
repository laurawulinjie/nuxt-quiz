# Quiz Web App

This front-end project is a multi-page quiz application built with Nuxt 3 that walks users from a welcome screen through a series of single and multiple-choice questions, complete with a progress bar, instant feedback, and a final score page.

## Setup

Make sure to install dependencies:

```bash
npm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
npm run dev
```

## Production

Build the application for production:

```bash
npm run build
```

Locally preview production build:

```bash
npm run preview
```

Check out the [deployment documentation](https://nuxt.com/docs/getting-started/deployment) for more information.
